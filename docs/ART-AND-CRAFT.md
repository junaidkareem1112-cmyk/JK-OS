# Art & Craft in JK OS

A complete **open-source creative suite** — every tool free, no licences, no
subscriptions. Find it in the **Art & Craft** folder on the Desktop and in
the Start menu.

## Pre-installed

| Tool | For |
|---|---|
| **GIMP** | Photo editing & raster graphics (Photoshop-style work) |
| **Inkscape** | Vector art — logos, illustrations, posters, stickers |
| **Krita** | Digital painting — the best open-source painting app |
| **MyPaint / Pinta** | Simple, friendly painting & drawing |
| **Scribus** | Desktop publishing — flyers, posters, brochures, books |
| **Audacity** | Audio editing, recording & music |
| **Tux Paint** | Art & craft for kids — stamps, brushes, magic tools |
| **LibreCAD** | 2D design & technical drawing |

## One-click installers (bigger tools)

| Tool | For |
|---|---|
| **Blender** | 3D modelling, animation, rendering |
| **Kdenlive** | Video editing (OpenShot noted as a lighter alternative) |
| **Darktable** | RAW photo studio & colour work |
| **FreeCAD** | 3D design & models for 3D printing |
| **Synfig Studio / Pencil2D** | 2D animation |
| **OBS Studio** | Screen recording & live streaming |

Every tool above is open source. Exact pre-installed vs one-click status is
verified at build time and stated honestly in each release's notes.
